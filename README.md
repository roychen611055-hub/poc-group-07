功能介紹：公司是良品衛浴設備有限公司，我的公司現在缺乏一套完善的訂單管理系統，包含：訂單輸入、訂單彙整、訂單到期通知的程式。主要要給多部門人員都能分享使用。訂單組接收到訂單之後將訂單資訊輸入到程序裡面，程序自行依照品類、交期、數量等等訊息進行排序並提供給廠務人員進行生產安排。廠務人員能夠在程序裡面看到所有訂單的內容,數量,交期,注意事項等，依照訂單內容進行製作，等製作完成之後可以在程序裡面勾選訂單完成的選項。當廠務人員完成了產品製作的勾選，出貨人員可以在程序裡面看到待出貨的排序，並且進行出貨的排程，當完成出貨的準備之後，出貨人員可以輸入出貨的單號並點選完成出貨的選項。財務人員可以在程序中看到產品已經完成出貨並要接著進行請款。等以上流程都處理完成後，程序就會跳出訂單已完成的訊息。 以上是要開發的程序中所包含的內容。 我想要使用以下連結的方式呈現程序的介面https://puma.taipei/heart-island

POC功能應用：AI 協助處理訂單異常示警

AI SBOM
AI可以用：AI可以從已輸入的訂單中抓取客戶名稱、產品數量、產品價格、交期。
AI不能用：


1. 痛：現在的各部門的資料獲取是分散的、收到訂單後、需要依靠訂單組一筆一筆的記錄並紙本或口頭告知廠務進行生產、廠務生產完之後需要由人員口頭進行下一步驟的告知。如此步驟造成訂單跟進上的瑕疵以及出貨後請款的步調不一緻性，造成管理困難。
